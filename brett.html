What is under it

It measures the answer, not the memory.

Most AI visibility tools ask a model what it remembers. For any local or mid-market business that is a fixed zero you cannot move, and measuring it harder does not help. When a real buyer asks ChatGPT the category question, the model searches the web and writes the answer out of what it finds. That layer is live, and it is winnable.

  • Runs with the models’ native web search switched on, the way a real buyer hits them.
  • Separates unprompted mentions from echoes — asking “is Acme good?” and getting “Acme” back is not visibility.
  • Flags disclaimers, so “I don’t have reliable information about them” never scores as a win.
  • Captures every source the models read before answering, and ranks them by influence.
  • Runs each prompt several times and reports the spread, because these models are not deterministic.

We built the scoring engine because the off-the-shelf ones were counting substring matches. Ours caught a case where a firm scored 93% on a tool that was matching a homonym — the real answer was that no model had ever heard of them. A number you can defend in a client meeting is the product.

Questions

The ones that actually come up.

Does GreenBrahma appear anywhere the client can see?

No. The widget carries your name and your accent colour. The embed is served from our CDN, so the script URL is visible to anyone who views source — if that matters to you, we can serve it from a subdomain you own.

Which engines does it cover?

ChatGPT, Claude, Perplexity and Gemini, all four included at the base price. We run them with web search on, which is how buyers actually use them. Memory-only baselines are available alongside, labelled as such, so you can show a client the gap between what the models know and what they can find.

Can I get the data out?

Yes. CSV export and a read API, both included. Every run is exportable with the full model response, the prompt, the run number and the sources, so you can take it into your own reporting if you prefer.

What if the number does not move?

Then you have found out early and cheaply, and the source panel tells you why. The honest answer is that the widget measures; it does not fix. The fixing is the work you bill for on top — schema markup, directory consistency, letting the AI crawlers in, earning citations on the properties the models actually read.

Is there a trial?

Fourteen days, one client, everything switched on. If you want it pointed at a prospect of yours rather than an existing client, that works too — it makes a better pitch than a deck.
